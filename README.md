# ymhsH1

## 梅岡時光機：楊梅高中 空照 × 衛星影像 1948–2026

`ymhs-showreel/index.html` 是一份單一 HTML 檔，內嵌 SVG，播放起來像一支約 180 秒的動態圖文短片（1920×1080、30 fps）。內容包含：

- 程式即時合成的背景音樂與音效（翻頁、快門、轉場）
- 瀏覽器預設語音的中文旁白，以及卡拉 OK 式字幕
- 章節跳轉、旁白／字幕／音效開關
- 「影像替換」：每個年份都可以載入自己從 Google 地球「歷史圖像」等來源截取的真實影像

用瀏覽器直接開啟即可，建議使用 Chrome 或 Edge。網址加上 `?t=秒數` 可以停在某一格畫面。製作說明請見 `ymhs-showreel/brief.md`。
